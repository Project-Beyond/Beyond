# Project BEYOND

### Build Everything Your Old Man Never Did.

Project BEYOND is a continuously evolving homelab built around one idea:

**Build, learn, experiment, document, and keep pushing beyond what I already know.**

BEYOND is a hands-on environment for experimenting with local AI, virtualization,
networking, cybersecurity, automation, storage, development, and self-hosted
infrastructure.

This isn't a production datacenter built with an unlimited budget. It's a real
homelab built piece by piece, using a mixture of consumer hardware, enterprise
equipment, repurposed systems, and whatever else can be made useful.

The goal is to document not only what works, but how it was built, what didn't
work, what was learned, and where the project goes next.

---

## The Lab

BEYOND is made up of several systems, each with its own role.

### 🖥️ Frankenstein — Compute

The primary Proxmox virtualization host and the foundation of the BEYOND
environment.

Frankenstein currently provides compute resources for the virtual machines and services
that make up the lab.

### 🤖 IRIS — Local AI

IRIS is BEYOND's locally hosted AI assistant.

The long-term goal is to develop IRIS into a distributed, locally hosted assistant
capable of interacting with BEYOND services and eventually extending throughout
the home using dedicated nodes.

### 🔨 Forge — Development

A dedicated development environment used for programming, testing, automation,
and building new BEYOND projects.

### 🔥 Hearth — Services & Gaming

Infrastructure for self-hosted applications and dedicated game servers.

### 📦 Stash — Storage

The storage and backup side of BEYOND.

Stash is being developed toward centralized storage for the lab, personal systems,
backups, and future BEYOND services.

## Current Direction

BEYOND began with repurposed consumer hardware and is gradually evolving toward
dedicated infrastructure.

Current and future projects include:

- Expanding from 2.5 GbE toward 10 GbE networking
- Expanding centralized storage
- Dedicated rack infrastructure
- GPU compute for local AI
- Multi-GPU experimentation
- Dedicated AI infrastructure for IRIS
- Improved monitoring and observability
- Network segmentation
- Backup and recovery testing
- Distributed IRIS nodes
- Infrastructure automation

## Build Philosophy

BEYOND isn't about having the newest or most expensive hardware.

It's about figuring out what can be built with what's available, understanding
how it works, measuring how it performs, breaking things, fixing them, and
documenting the process.

Whenever hardware is evaluated as part of BEYOND, the goal is to test it in a
real environment rather than simply unbox it.

Testing may include:

- Installation and configuration
- Compatibility
- Performance
- Reliability
- Power and thermal behavior
- Integration with existing infrastructure
- Long-term use
- Limitations and problems encountered

## Hardware Testing & Collaboration

BEYOND is open to testing hardware and technology that fits the goals of the
project.

Products provided by manufacturers or vendors will be clearly disclosed.
Receiving hardware does not guarantee a positive review.

The objective is always the same:

**Build it. Test it. Learn from it. Document it.**
